# Voyce Member Portal\n\nStatic portal for deployment to Vercel.\n\n## Files\n- index.html — main portal page\n- oyce_portal_data.json — member data used by the portal\n\n## Deploy to Vercel\n1. Push this folder to GitHub.\n2. In Vercel, create a new project and point the root directory to the github folder.\n3. No build step is required — Vercel will serve the static index.html.\n\n## Update workflow\n- Edit github/index.html or github/voyce_portal_data.json locally.\n- Push changes to GitHub.\n- Vercel will automatically redeploy from GitHub.\n
